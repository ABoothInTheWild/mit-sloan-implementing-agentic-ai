# MIT-AGAI Cohort, August 31, 2026

This folder contains the course materials for the **Implementing Agentic AI: Building Your Organizational
Playbook** cohort starting August 31, 2026. Faculty Director: Paul McDonagh-Smith, MIT Sloan Executive
Education.

## Live session status

**Not yet held.** The `Live_Session/` folder is currently a placeholder and will be filled in (slides
plus recap README) once that session happens.

## Module map

* **[Module 0: Orientation](./Module_00/README.md)**: program introduction, the reactive-to-agentic
  reframing, the explore/implement/scale arc, and the Honor Code and Program Policies.
* **Module 1: Understanding Agentic AI**: what agentic AI actually is, the AI continuum, the
  reactive-vs-proactive distinction, the architecture that turns an LLM into an agent, and where genuine
  organizational value (and constraint) sits. Materials not yet released.
* **Module 2: Designing and Deploying Agentic Systems**: memory and learning, failure modes and external
  safeguards, multi-agent and multimodal systems, build-vs-buy-vs-stack, human-in-the-loop thresholds,
  AgentOps, and task decomposition. Materials not yet released.
* **Module 3: Scaling Agentic AI Responsibly**: the autonomy spectrum and four-layer safeguard
  architecture, the "comparison that matters," the shift from code to intent, organizational readiness,
  multi-agent orchestration research, and agency law, disclosure, bias, and workforce accountability.
  Materials not yet released.

Each module README summarizes that module's lesson, media-set, and podcast content, drawn from the
transcripts in its `Downloads/` folder.
