# MIT Sloan: Implementing Agentic AI

This repository contains course materials, lesson content, and live-session resources for **Implementing
Agentic AI: Building Your Organizational Playbook** — an MIT Sloan Executive Education / MIT Schwarzman
College of Computing program (delivered in collaboration with GetSmarter), facilitated by the Head
Program Instructor. The program's Faculty Director is Paul McDonagh-Smith, Senior Lecturer in
Information Technology at MIT Sloan.

## What the program covers

The program runs across an orientation module plus three content modules, building a deliberate arc:

* **Orientation** — program introduction, Faculty Director welcome, the overall 3-module arc, honor
  code and program policies.
* **Module 1** — what Agentic AI actually is: the shift from reactive, prompt-response AI to proactive
  agents that plan, use tools, and execute multi-step workflows, and where that creates genuine
  organizational value versus where constraints still exist.
* **Module 2** — implementation and architecture: the scaffolding that turns a model into a reliable
  goal-directed agent, and how single agents become orchestrated multi-agent systems across real
  applied workflows (customer-facing, operational/supply chain, risk/compliance).
* **Module 3** — scaling and governance: moving from a successful pilot to enterprise-scale deployment
  without losing control — security, error propagation, accountability gaps, and safeguards that earn
  trust rather than just mitigate risk.

## Repository structure

Folders are named `MIT-AGAI-<START_DATE>` for each cohort.

```
MIT-AGAI-<START_DATE>/
  README.md              cohort overview (module map, live-session status)
  Module_00/              Orientation
  Module_01/              Module 1 — Understanding Agentic AI
  Module_02/              Module 2 — Architecting Agentic Systems
  Module_03/              Module 3 — Scaling Agentic AI with Governance
    README.md              authored "Big Ideas" module summary (the main maintained artifact)
    Downloads/              lesson/media/podcast transcript PDFs and supporting readings (source material)
  Live_Session/            live-session slides/recap once that cohort's session has happened
    README.md
```
